These components come from interior.dev (https://www.interior.dev, MIT licence, see LICENSE).
They are copied in as source, the way the library is meant to be used, with two changes:
the accent and dark surface colours were swapped for this app's palette, and the
"use client" line (only meaningful in Next.js) was removed.

To pull in a newer copy of one: replace the file with the version from
https://github.com/ddoemonn/interior/tree/main/components/interior and re-apply the colours.
